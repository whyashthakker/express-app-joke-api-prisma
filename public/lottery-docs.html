🎯 Game Overview

The Price Lottery is a competitive game where players try to win by:

1
Call GET /prices repeatedly until you get price = 1
2
Receive a math challenge that you must solve within 60 seconds
3
Submit your answer via POST /prices/solve
4
Win if your answer is correct and get announced on Discord!
⚠️ Rate Limiting: Maximum 1 request per second to /prices. Exceeding this will silence you for 10 seconds!

🔗 API Endpoints

GET /prices
Get a random price between 1-100. Price = 1 triggers a math challenge.

Response (Normal):

{ "price": 47, "timestamp": "2023-12-18T10:30:00Z", "lottery": { "isWinner": false, "winningNumber": 1, "probability": "1%", "odds": "1 in 100" }, "rateLimit": { "remainingRequests": 0, "resetIn": "1 second" } }

Response (Jackpot - Price = 1):

{ "price": 1, "lottery": { "isWinner": true }, "challenge": { "status": "JACKPOT! You got price = 1!", "challengeId": "challenge_1703123456_abc123", "question": "What is 127 + 394?", "timeLimit": "60 seconds", "expiresAt": "2023-12-18T10:31:00Z", "instructions": "POST /prices/docs/solve with answer", "warning": "You have 60 seconds to solve this!" } }
POST /prices/solve
Submit your answer to the math challenge within 60 seconds.

Request Body:

{ "challengeId": "challenge_1703123456_abc123", "answer": 521, "winner": "YourName" }

Response (Success):

{ "success": true, "winner": "YourName", "message": "🎉 CONGRATULATIONS! YourName won the price lottery!", "challenge": { "question": "What is 127 + 394?", "correctAnswer": 521, "yourAnswer": 521, "solveTime": "3 seconds" }, "achievement": "You beat the odds and solved the math problem!", "announcement": "Winner announced on Discord and live feeds!" }

📋 Rules & Constraints

  • Rate Limit: Maximum 1 request per second to /prices
  • Silence Penalty: Exceeding 1 RPS results in 10-second silence
  • Time Limit: 60 seconds to solve math challenges
  • IP Security: Only the original requester can solve their challenge
  • One Shot: Each challenge can only be attempted once
  • Math Types: Addition, subtraction, and multiplication problems

🧮 Math Challenge Examples:

Easy: What is 42 + 17? Medium: What is 156 - 89? Hard: What is 23 * 18?

💡 Pro Tips:
